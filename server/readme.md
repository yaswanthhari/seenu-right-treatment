# 🏥 Seenu's Right Treatment - Cancer Care Platform

A comprehensive cancer awareness and support platform that helps patients:
- Find cancer hospitals near them
- Learn about early detection
- Understand treatment pathways
- Get financial assistance
- Connect with support services

## 🌟 Features
- **Hospital Search**: Find cancer treatment centers by city
- **Early Detection Guide**: Symptoms and screening information
- **Treatment Pathway**: Step-by-step treatment guidance
- **Financial Help**: Government schemes and support
- **Emergency Contacts**: Immediate help resources

## 🏥 Available Hospitals
- Tata Memorial Hospital (Mumbai)
- AIIMS Cancer Center (Delhi)
- Apollo Cancer Institute (Chennai)
- Multiple other cancer centers across India

## 🚀 How to Run Locally
1. Clone this repository
2. Install dependencies: `npm install express cors`
3. Run server: `node server-final.js`
4. Open browser: `http://localhost:5000`
